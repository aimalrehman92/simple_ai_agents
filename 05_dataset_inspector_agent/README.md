# Dataset Inspector Agent

A lightweight agent for loading a CSV file, inspecting its structure, checking missing values, previewing rows, and summarizing individual columns.

## Available tools

- `load_csv`
- `get_dataset_shape`
- `get_column_names`
- `calculate_missing_values`
- `summarize_column`
- `preview_rows`
- `get_loaded_dataset`

## Run

From the project root:

```bash
python 05_dataset_inspector_agent/main.py
