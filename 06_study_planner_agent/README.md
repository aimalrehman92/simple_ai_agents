# Study Planner Agent

A simple agent for estimating study time, prioritizing topics, building a day-by-day schedule, and tracking time remaining before a deadline.

## Available tools

- `estimate_topic_hours`
- `prioritize_topics`
- `create_study_schedule`
- `calculate_days_until_deadline`

## Run

From the project root:

```bash
python 06_study_planner_agent/main.py
