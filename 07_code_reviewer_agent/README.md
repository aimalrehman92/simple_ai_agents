# Python Code Reviewer Agent

A lightweight agent for inspecting Python files, checking syntax, summarizing code structure, finding long lines and large functions, and reporting missing docstrings.

## Available tools

- `check_syntax`
- `summarize_structure`
- `find_long_lines`
- `find_large_functions`
- `find_missing_docstrings`
- `review_python_file`

## Run

From the project root:

```bash
python 07_code_reviewer_agent/main.py
