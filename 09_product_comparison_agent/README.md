# Product Comparison Agent

A simple agent for comparing user-provided products, filtering options by budget, identifying the cheapest choice, and ranking products by price, rating, and required features.

## Available tools

- `compare_products`
- `filter_by_budget`
- `find_cheapest_product`
- `rank_products`

## Run

From the project root:

```bash
python 09_product_comparison_agent/main.py
